# The Last Echo

### A Story-Driven Supernatural Horror Game

**The Last Echo** is a web-based, chapter-driven horror game focused on exploration, investigation, decision-making, and survival. Players uncover a mysterious story through clues, puzzles, supernatural anomalies, and choices that influence the progression and ending of the game.

## Key Features

* Chapter-based story progression
* Interactive exploration and clue discovery
* Supernatural anomaly encounters
* Power selection and charge system
* Escape-room style puzzles
* Stealth and reaction-based gameplay
* 5-life survival system with revive potions
* Meaningful choices and branching events
* Sound-based horror interactions
* Multiple endings
* Save and load using browser storage

## Technology Stack

* **HTML5**
* **CSS3**
* **JavaScript**
* **Web Audio API**
* **LocalStorage**

## Running the Project

The game can be run locally using a simple web server:

```bash
python -m http.server 8000
```

Open the provided port in a browser to start the game.

**Explore → Discover Clues → Solve Puzzles → Make Decisions → Survive Anomalies → Uncover the Truth**
